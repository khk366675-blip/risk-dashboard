# 외부 자료·메모 편집

위치: 종목의 투자포인트 → 연결 자료 → 자료 직접 추가.

- 글: 본문, 제목, 인용, 목록. 구성 요소의 순서 이동·삭제·직전 삭제 복원.
- 표: 셀 직접 입력, 엑셀 범위 붙여넣기(탭 구분, 따옴표 안의 줄바꿈 포함), 행·열 추가 및 끝 행·열 삭제/복원.
- 그래프: 같은 표를 선/막대그래프로 표시. 첫 열은 항목, 나머지는 수치. 단위는 따로 입력한다. 원표는 항상 남기며, 빈칸·미확인·단위 포함 문자열·수식은 0으로 바꾸거나 계산하지 않는다. 지수화하지 않으며 선은 누락값을 연결하지 않는다.
- 이미지: PNG/JPG/WebP 파일 선택 또는 캡처 이미지 붙여넣기. 메모당 3개, 원파일 15MB 이하. 브라우저에서 최대 변 1,800px/이미지 350KB 이하의 PNG/JPEG로 조정한 저장용 사본을 만든다. 원본 파일은 바꾸지 않는다. 표/이미지 설명 포함 메모 6,000자, 표 40행×8열.
- `넓게 쓰기`에서 자료 부가정보를 잠시 접고 메모에 집중한다. 하단 저장 버튼은 고정되어 있다. 저장한 메모는 `메모·표·이미지 보기`에서 넓게 열며 이미지는 다시 확대할 수 있다.

기존 일반 텍스트는 그대로 유지한다. 새 형식은 별도 SQLite 테이블에 저장하고, 내용·서식·이미지를 포함한 스냅샷 해시로 중복/변경 요청을 구분한다. 근거와 메모를 한 트랜잭션으로 저장한다. 연결 해제는 보관이며 자료 갱신으로 덮어쓰지 않는다. 저장 실패 후 같은 내용으로 재시도하면 같은 요청 식별자를 사용한다.

AI에는 글·표·이미지 설명의 텍스트만 기존 미리보기/동의 흐름으로 전달한다. 이미지 본문은 보내거나 판독하지 않는다. 직접 입력 수치를 수집·검증된 DART 수치로 취급하지 않는다. HTML/SVG/외부 이미지 URL은 허용하지 않는다.

모바일 스냅샷에 표·그래프 설정·이미지 사본도 포함한다. 실제 원격 화면에서 새 형식을 보려면 업데이트된 코드의 배포와 모바일 게시가 필요하다. 이번 작업에서는 원격 게시/배포를 실행하지 않았다. 로컬 백업은 SQLite에 포함된 원메모를 보존한다. 기존 Markdown 내보내기는 텍스트·표 수치·이미지 설명 중심이며 이미지 파일을 따로 내보내지는 않는다.

검증: 웹 로직 테스트 102개 통과, production 빌드, 격리된 HTTP 저장/조회/중복/충돌/요청 출처/용량/형식 제한 테스트, 모바일 스냅샷 포함 확인. 브라우저에서 표와 선그래프를 작성·저장·다시 열고, 화면 캡처를 붙여넣어 저장 후 이미지 로딩을 확인했다. 테스트 자료는 사용자 저장소와 분리한다.

```text
node --experimental-strip-types --test tests/rich-memo.test.mjs tests/manual-evidence.test.mjs tests/thesis-evidence-ai.test.mjs tests/mobile-dashboard.test.mjs
node --experimental-strip-types tests/rich-memo.integration.mjs
```
