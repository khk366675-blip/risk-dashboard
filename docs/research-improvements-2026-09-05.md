# 2026-09-05 로컬 개선

## 사용 위치

- 주요 화면 사이드바: `검색` (Ctrl/Cmd+K), `자료 저장`. 종목 미지정 자료는 Learning에서 나중에 종목을 연결.
- 투자포인트: `버전 N`에서 저장본 비교·편집기로 복원. `내 검증 항목`을 펼쳐 답변·남은 질문·사용할 자료를 기록하고 저장한 뒤 `이 질문만 AI 검토`.
- 초안: 투자포인트·Learning·리서치 로그·빠른 저장·모바일 메모의 미저장 글을 해당 브라우저 localStorage에 보관. 복원은 명시적으로 선택. 브라우저 데이터 삭제 시 초안은 소실되므로 정식 저장과 백업을 대체하지 않음.
- 재무 추이: 출처 포함 CSV (원 단위 값, 단독 분기/기말 잔액, 연결/별도, 원문, 실행·수집 정보). Excel에서는 종목코드를 텍스트 열로 가져올 것.
- Research View: 가설·질문·답변·연결 근거·KPI·리서치 로그를 출처 포함 Markdown으로 저장.
- 모바일 메모: 종목 미지정은 Learning, 종목 지정은 해당 리서치 로그로 PC 동기화. 기존 클라우드 스키마 호환을 위해 내부 코드 `000000`을 일반 메모용으로 예약하며 화면에는 종목코드로 노출하지 않음.

## 데이터 일관성

- Markets/Radar/로컬 모바일 게시가 빌드에 묶인 JSON이 아닌 요청 시점 파일을 읽음. 후보 목록과 요약 개수가 불일치하면 오류로 드러냄.
- Radar 미리보기의 65거래일 제한 제거. 기존 짧은 미리보기도 동일 기준일·겹치는 종가가 일치하는 로컬 전체 시세가 있으면 읽기 전용으로 확장. 새 수집이나 기존 사용자 DB 수정 없음. `보유 전체`는 저장된 전체 기간이며 상장 이후 전체라는 의미는 아님.
- 이미 생성된 Radar 결과는 당시 규칙·숫자를 유지. 다음 실행부터 v8: TTM 연속 분기·재무 기준 검사, 전년 동기 기준 비교, 누적 현금흐름 차감 시 직전 분기 누락/기준 혼합 방지, Dislocation 중복 하락 근거 제외. 고점 대비 -55% 필수 게이트 유지.
- EV/영업이익 근삿값을 EBITDA 배율로 부르지 않도록 수정. 기존 DB 컬럼명은 호환 목적으로 유지.
- AI 수집일과 대상 기간을 분리. 발췌 길이 및 잘림 상태를 전송 미리보기에 표시. 질문별 선택 자료와 답변은 실행 입력·시그니처에 포함. 모델과 비용 한도는 유지. 자동 호출·링크 방문 없음.

## 검증 및 적용 범위

별도 임시 저장소에서 저장/버전/질문/선택 AI 입력/검색/내보내기/가격 기간/갱신 파일 읽기를 회귀 검증. AI 응답은 모의 응답을 사용하며 실제 품질평가나 유료 API 요청은 하지 않음. 전체 Radar 수집도 실행하지 않음.

기존 관심종목·투자포인트·Learning 원본 및 사용자 생성 Radar/Markets 파일은 보존. 변경 전 외부 폴더 백업 완료. GitHub push·Vercel 배포·Supabase 게시/동기화는 이번 작업에서 실행하지 않음. 모바일 UI 변경은 별도 코드 배포가 필요하며 최신 자료는 로컬 게시 버튼으로 전달.
