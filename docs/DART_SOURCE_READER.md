# 공시 원문 작업면 — 로컬 문서 수집·열람

2026-09-03. 외부 AI 연결/품질 검증은 사용자 요청으로 보류했다. 이 작업은 기존 DART 연결로 보고서를 수집하고 사람이 원문을 확인하는 기능이며 AI 호출·자동 분석·투자 판단은 없다.

## 범위와 사용 흐름

관심종목 상세 → `공시 원문` → 정기보고서 선택 → `출처·관리` → `이 보고서 원문 수집` → 목차 분류/검색 → 문단·표 확인 → 투자포인트 연결 또는 DART 원문.

- 원문 탭은 종목 요약을 기본으로 접고 본문 높이를 우선한다. 상단 `종목 정보`를 펼치면 가격·자료 최신화 등 기존 기능을 사용할 수 있다. 다른 상세 탭은 기존 요약을 유지한다.
- 원문 재수집·저장 버전 선택·추출 경고·원본 해시는 `출처·관리` 우측 패널에 모은다. 패널은 본문을 세로로 밀지 않으며, 닫아도 선택한 목차와 읽던 위치를 유지한다. 수집 실패·조회 시각·이전 저장본 열람 여부는 본문 위에도 표시한다. 목차와 본문은 각각 내부 스크롤한다.

- 기존에 수집한 공시 목록에서 접수번호와 DART 링크가 일치하는 사업·분기·반기보고서만 선택한다. 임의 URL·접수번호 전송은 거부한다. 정정 보고서는 별도 접수번호로 남긴다. 공시 목록 이후 나온 정정이 자동으로 포함됐다고 가정하지 않는다.
- 수집 버튼은 로컬 Python 작업을 시작한다. 창을 닫아도 작업이 계속되며 열람/새로고침만으로 수집하지 않는다. 동일 요청·진행 중 작업을 중복 실행하지 않는다. 같은 저장소에서는 원문 작업 한 개씩 진행한다.
- 저장본은 계속 읽을 수 있다. 24시간 내 일반 수집 요청은 성공 저장본을 재사용한다. `원문 다시 수집`은 캐시를 건너뛰고 해당 접수번호를 다시 요청한다. 보고서 목록 자체를 최신화하려면 기존 `자료 최신화`를 사용한다.
- DART 키와 Python 실행 환경은 기존 관심종목 수집기와 동일하다. 환경 파일 탐색 순서는 `RADAR_ENV_FILE`, `.env.local`, `.env`, `../ai-invest/.env`. 첫 존재 파일을 사용하며 환경 변수를 덮어쓰지 않는다. 비밀 키를 복사·로그·백업·Git에 넣지 않는다.

## 추출과 출처 경계

[OpenDART 공식 원문 API](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019003)는 접수번호와 인증키로 ZIP 원본을 제공한다. [이용약관](https://opendart.fss.or.kr/intro/terms.do)의 요청 한도를 존중하고 오류를 표시한다. 로컬 개인 열람 범위이며 공개 재배포 기능은 없다.

- 원본 ZIP은 바꾸지 않는다. 접수번호에 해당하는 XML 또는 유일한 XML만 주 문서로 선정한다. 모호한 다중 XML은 미지원으로 남긴다.
- 목차, 문단, 표, 행/열 병합을 추출한다. 숫자·단위·연결/별도·기간 표기는 원문 텍스트로 보존하고 수치 계산은 하지 않는다. 서식·줄바꿈·페이지 위치가 원문과 같다는 보장은 없다.
- 목차의 사업/주석/재무 분류는 제목과 상위 절 기반의 탐색 보조다. 왼쪽 목차 검색은 제목 검색이고, 상단 `근거 찾기`는 로컬에 저장한 추출본의 문단·표 전체를 검색한다. 기본은 최근 저장본이며 보고서·목차 분류·이전 저장본 포함 여부를 명시적으로 고른다.
- 본문 검색은 공백으로 나눈 모든 검색어가 같은 문단·표에 있는 결과만 반환한다. 접수번호·저장 버전·절·블록·XPath와 발췌를 표시하고 원문 위치 이동 또는 투자포인트 수동 연결을 제공한다. 일부 저장본의 무결성 오류, 검색 버전/결과 상한, 검색 범위는 숨기지 않는다. 검색 결과 없음은 근거 부재를 뜻하지 않는다.
- `변화 대조`는 저장된 서로 다른 두 정기보고서의 같은 제목 목차를 맞춘 뒤 문단·표의 정확한 동일 문구를 기준으로 정렬한다. 정렬 구간의 교체는 `내용 변경`, 최근에만 남은 항목은 `새로 등장`, 이전에만 남은 항목은 `이전 문구 제외`로 표시한다. 큰 목차의 순서 기반 fallback과 결과 상한을 경고한다. 이 분류는 중요도·호재·악재 판정이 아니며 단순 기간·숫자·서식 변화도 포함할 수 있다.
- 변화 양쪽의 접수번호·버전·절·블록·XPath를 보존하고 각각 원문 위치로 이동하거나 투자포인트에 수동 연결할 수 있다. 보고서가 두 개 미만이면 자동 수집하지 않고 필요한 저장 범위를 안내한다.
- 각 문단·표는 안정된 ID와 주 XML 내 XPath를 가진다. 화면 번호에 마우스를 올리면 파일/ID/경로를 확인할 수 있다. 원문 접수 링크·원본 해시·파서 버전·수집 시각도 표시한다.
- 각 문단·표의 연결 버튼은 선택한 투자포인트와 관계(`뒷받침 검토`, `반대·약화 검토`, `참고·미확인`), 선택 메모를 저장한다. 서버가 해당 불변 저장본에서 절·블록을 다시 확인하고 당시 발췌·XPath를 복사하므로 클라이언트가 원문을 임의로 만들어 저장할 수 없다.
- 실제 DART XML에 나온 비이스케이프 `&`와 비정상 꺾쇠 한글 표제만 표시용으로 이스케이프하고 처리 개수와 경고를 기록한다. CDATA·주석은 이 처리에서 제외한다. 중첩 태그 구조를 임의 복구하지 않고, 그래도 파싱되지 않으면 미지원이다.
- 외부 엔터티, 내부 DTD, 임의 외부 문서 요청, 원문 스크립트 실행은 허용하지 않는다. 원문 HTML을 브라우저에 주입하지 않고 문자열·구조화된 셀만 렌더링한다.
- 이미지·PDF·외부 첨부·XBRL 연결 파일·OCR는 미지원이다. 중첩 표는 경고와 함께 텍스트로 표시한다. 원문에 내장된 모든 자산과 공시 전체를 해석한 결과가 아니다.

## 저장과 복구

- `filing_documents`: 접수번호·제목·작업 ID·상태·조회 시각·최근 사용 가능한 버전.
- `filing_document_versions`: 원본 해시·추출 해시·파서 버전·수집일·범위/경고. 원본 바이트와 파서 버전이 같으면 같은 버전이다. 추출 방식 변경 시 파서 버전을 올린다.
- `data/research/documents/{종목}/{접수번호}/{SHA-256}.zip|json`: 불변 원본·추출본. 실패나 이후 정정으로 기존 파일을 덮어쓰지 않는다. 미지원 ZIP도 기록하되 이전 사용 가능한 추출본을 숨기지 않는다.
- 새 수집 실패 시 이전 저장본과 기존 사용자 글을 유지한다. 만료 작업은 응답 끊김으로 표시하며 자동 재실행하지 않는다.
- 백업은 DB가 참조하는 모든 원본/추출 파일을 해시 검증 후 포함한다. 빠진 파일이나 변조가 있으면 백업을 게시하지 않는다. 기존 문서 기능 도입 전 백업은 계속 복구할 수 있다. 복구된 진행 중 수집은 오류로 표시하고 재개하지 않는다.
- 투자포인트·AI 질문·자료 확인 기준을 수정하지 않는다. 원문을 읽었다는 이유로 검토 완료 처리하지 않는다.
- 원문 연결은 포인트의 정확한 수정 버전과 문서의 접수번호·저장 버전을 고정한다. 이후 포인트나 공시가 바뀌어도 기존 연결은 당시 기준으로 남고, 연결 해제는 행 삭제가 아니라 보관 처리한다. 같은 위치를 같은 포인트에 중복 연결하지 않는다.

## 검증과 미지원 작업

`npm run test:documents`, Python `test_documents.py`/백업 테스트, 기존 단위 테스트, `tests/followup-api-smoke.mjs`, production build로 검사한다. 실제 다운로드한 성호전자 반기보고서(접수 20260814003108)를 별도 저장소에서 추출·목차 이동·표 렌더링에 사용했다. 이것은 한 문서의 검증이며 모든 회사·모든 보고서 형식의 정상 해석을 보장하지 않는다.

읽기 공간 개선은 같은 격리 저장본·수집 실패 안내가 표시된 상태에서 비교했다. 본문 높이는 1280×720에서 176→477px, 390×844에서 160→521px다. 전체 페이지 넘침 없이 목차·본문 내부 스크롤 영역, 출처 패널을 열 때 높이 유지, 종목 정보 토글 시 목차 유지, 주석 49개 블록의 다음 페이지 이동을 확인했다. 레이아웃 변경 후 문서/종목 관련 Node 테스트 32개, lint, production build를 통과했다.

투자포인트와 특정 원문 문단·표를 수동 연결하고 투자포인트 우측 패널에서 발췌·메모·출처를 다시 보는 기능을 구현했다. 내부 링크는 고정된 접수번호·문서 버전·절·블록이 들어 있는 페이지로 이동하고 해당 블록을 강조한다. 연결만으로 사실이 확인됐거나 가설이 입증됐다고 표시하지 않는다. 저장본 본문 전체 검색, 검색 결과의 직접 연결, 두 저장 보고서의 규칙 기반 변화 대조까지 구현했다. 원문 자동 선정/일괄 수집, AI 근거 대조, 투자포인트별 변화 자동 매칭은 후속 작업이다.
