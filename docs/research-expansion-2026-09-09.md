# 리서치 확장 · 2026-09-09

## 사용 위치

- **수집 작업**: 우측 하단 버튼. Markets/Radar는 작업 등록 후 별도 Python 프로세스가 수집한다. 페이지 이동·웹서버 재시작과 독립적이며 PC 종료 후 자동 재실행하지 않는다. 같은 종류의 진행 중 작업은 재사용한다. 완료 결과·실패·재시도를 패널에서 확인한다.
- **기업 비교**: 검색으로 관심종목 밖의 기업도 추가한다. 비교 조합과 이유를 저장하며 기업별 `자료 최신화`를 제공한다. 관심종목과 별도 `data/research/peers` 저장소를 사용한다. 한 조합 2~5개, 분기/연간/TTM의 동일 사업연도 기간. 결측은 빈칸이며 연결/별도는 표와 선 모양으로 구분한다. 기존 사업 KPI와 현재 배수는 별도 섹션으로 유지한다.
- **종목 → 재무 추이**: 손익·현금흐름, 매출·운전자본, 유형자산 취득, 현금·차입금, 기본 재무. 분기/최근 5개 연간/TTM 전환. 클릭하면 원계정·원금액·공시·파생 계산의 피연산자를 확인한다. 기존 기본 지표의 투자포인트 관측 연결을 유지하며 CSV는 선택 기간·원단위·계산 근거를 포함한다.
- **종목 → 공시 원문 → 리포트·IR PDF**: 25MB/1,000페이지 이하, 비암호화 PDF를 로컬 첨부. 전체 높이의 문서 화면, 페이지 전환, 텍스트 선택·하이라이트·메모·투자포인트 관계 저장. 스캔/표는 페이지를 보며 인용을 직접 입력한다. 기존 연결 자료와 질문의 근거 선택에서 재사용한다. PDF 원본을 자동으로 AI에 전송하거나 모바일 게시하지 않는다.

새 자료는 기존 백업에 포함한다. PDF는 SHA-256 검증, 발췌와 근거는 한 트랜잭션으로 저장한다. 원래 관심종목/글/AI 결과는 초기화하지 않는다.

## 재무 산식과 제한

공식 기준: [DART 전체 재무제표 API](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS003&apiId=2019020), [다중회사 주요계정 API](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS003&apiId=2019017).

- KRW/원, 보고서 기간·접수번호·연결/별도 일치 여부를 검사한다. 정확한 계정 ID/명칭만 매핑한다. 값이 다른 중복 계정은 임의 선택하지 않는다. 결측·대시·비정상 값은 0이 아니다.
- 중간 손익의 `thstrm_amount`는 3개월 값이다. 4분기는 연간에서 3분기 누적을 차감한다. 현금흐름/유형자산 취득은 동년 누적 차감으로 단독 분기를 계산한다. 기말 잔액은 차감하지 않는다.
- 동일 사업연도·기준의 공시 누적액과 각 시점 분기 합계가 다르면 원금액을 유지하고 `comparison_status` 및 차이를 보존한다. 정정·재작성 원인이 확인된 것으로 단정하지 않는다. 해당 구간의 TTM 합산은 차단한다.
- TTM은 연속 4개 분기, 동일 기준, 해당 지표의 금액과 비교 가능성이 모두 확인될 때만 계산한다. 누락 기간이나 연결/별도 변경 구간을 차트로 연결하지 않는다.
- 관심종목의 연결 PER/PBR은 지배주주 순이익/자본, ROE는 기초·기말 평균자본을 사용한다. 별도는 해당 회사 순이익/자본을 사용한다. 주가·시총 기준일과 보고서 기간은 다르므로 현재 시점 참고 배수이지 과거 밸류에이션이 아니다.
- Radar는 별도 발견 도구로서 기존 **기말 자본 기준 ROE** 조건을 유지한다. 주요계정 배수는 전체 순이익/자본의 참고 배수이며 관심종목의 지배주주 기준 배수와 다를 수 있다. 원계정 중복·통화 확인·누적 합계 차이 검사를 강화했다. 금융비용 전체를 이자비용으로 대체하지 않으며, 일부 차입금 합계로 총차입금/EV를 만들지 않는다. 새 수집본에는 산식 메타데이터를 남긴다.
- 유형자산 취득은 무형자산 취득 등을 포함한 전체 CAPEX가 아니다. 유동/비유동 차입금과 사채는 중복 가능성 때문에 자동 합산하지 않는다.
- 기존 수집본은 기존 기준일로 보존한다. 종목의 `자료 최신화` 후 24분기·최근 5개 연간 및 새 계정 검증이 반영된다. 재시도에서도 이전 파서 자료의 재검증은 건너뛰지 않는다. IPO 이전 등 미제공 보고서는 표시하되 다른 정상 자료 수집을 막지 않는다.

## 검증 기록

- 저장된 **20개 기업·198개 보고서**, 직접 원금액/연간 대사 **663건**. 연간 대사 불일치 8건은 원금액을 수정하지 않고 비교 제한 상태로 식별했다. 별도 테스트가 이 경우 TTM 계산을 차단하는지 확인한다. 이는 회계 감사나 모든 회사의 공시 정확성 보증이 아니다.
- DART API를 실제 1회 조회: 휴온스글로벌 2026 반기 연결, 접수번호 `20260814004205`. 매출/영업이익/순이익/누적 OCF/현금/자본/부채/재고/매출채권/유형자산 취득 **10개 금액 일치**. 예: 2Q 매출 214,141,005,638원, 누적 OCF 52,388,519,956원. 1Q 누적 30,096,807,825원을 차감한 2Q OCF는 22,291,712,131원이다.
- 단위/결측/중복/통화/연결·별도/사업연도/접수번호/Q4/YTD/TTM/재작성 불일치/지배주주 배수/평균자본/백업 복구 회귀 테스트.
- 별도 임시 DB의 production HTTP 테스트: 작업 중복·출처 제한·실행 실패, 비교 기업의 관심종목 분리, 조합 저장, PDF 실제 업로드·중복·다운로드 동일성·페이지/버전/영역 검사·자료 연결. PDF.js 공개 테스트 PDF 사용.
- 브라우저에서 PDF 드래그 발췌→메모 저장→페이지 이동→저장 위치 복귀/하이라이트와 재무 원계정 패널을 확인했다.
- 전체 Radar/Markets 수집 및 실제 유료 AI는 실행하지 않았다. 검증용 임시 기록은 사용자 저장소와 분리한다. GitHub push, 배포, 모바일 게시/동기화는 이번 작업 범위가 아니다.
