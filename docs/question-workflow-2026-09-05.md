# 검증 질문 작업면과 로컬 채택 오류 수정

- 투자포인트 안에 `투자포인트 작성 / 검증 질문` 탭을 두고 기존 질문 편집 목록을 이동했다. 동일한 `content.checks`를 사용하므로 기존 질문·답변·버전은 유지한다.
- 수동 질문과 사용자가 채택한 AI 질문을 한 목록에서 편집한다. AI 패널은 미채택 `AI 질문 제안`이며 채택 후 검증 질문 탭의 추가된 질문으로 이동한다.
- 질문 선택 → 내 답변 → 남은 확인 사항 → 근거 연결 → 저장. 상태는 사용자가 직접 선택한다. 여러 질문을 편집한 뒤 저장하면 투자포인트의 새 버전 하나로 보존한다.
- 기존 공시·재무·수동 자료를 선택하거나 `링크·메모 추가`로 자료를 등록한다. 새 자료는 별도 저장되며 질문 연결은 하단 저장으로 확정한다. 연결 자료의 저장 발췌를 펼쳐 확인할 수 있다.
- 넓은 작업면에서는 질문 목록과 답변을 독립 스크롤하는 좌우 패널로, 좁은 작업면에서는 질문 선택 메뉴와 답변 패널로 표시한다.
- Next가 request.url을 실행 호스트로 정규화할 때 localhost/127.0.0.1 간 같은 출처 검사가 실패했다. 실제 HTTP Host를 엄격한 loopback allowlist로 검증하고 Origin과 비교한다. 다른 출처·포트, 외부 Host, Vercel, cross-site 요청은 계속 차단한다. forwarded-host는 신뢰하지 않는다.

검증:

- `node --experimental-strip-types --test tests/*.test.mjs`: 90개 통과.
- `node --experimental-strip-types tests/question-flow.integration.mjs`: 격리된 임시 SQLite와 production 서버에서 양쪽 로컬 호스트의 채택·재시도·자료 추가·답변 저장·재조회·구버전 충돌·교차출처 차단 확인. AI는 mock 응답만 사용한다. 실제 사용자 저장소를 변경하지 않는다.
- lint 및 production build, 실제 종목 화면의 탭 전환·자료 열람 확인.
